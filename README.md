# Monopoly Game 🎲🏠

A digital version of the classic Monopoly board game, built to bring the fun of buying, trading, and bankrupting your friends straight to your screen.

## Features
- 🎯 Turn-based gameplay for multiple players
- 🏘️ Buy, sell, and trade properties
- 🎲 Dice roll mechanics with automatic movement
- 💰 In-game currency and rent system
- 🏢 Houses, hotels, and property upgrades
- ⚖️ Chance & Community Chest cards
- 🚔 Jail rules and mechanics
- 🖥️ [GUI/Console] based interface
